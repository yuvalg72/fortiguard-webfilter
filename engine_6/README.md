# Legacy engine_6 implementation

This directory is retained from the upstream `SystemJargon/fortiguard-webfilter` project for historical reference.

It contains older PowerShell/Python lookup logic and is not the supported execution path in this fork. Use the root-level `webfilter.py` or `FortiWebFilter-BulkScan.ps1` instead.

The legacy files are intentionally excluded from normal CI behavior because their transport and parsing assumptions predate the maintained implementation.
